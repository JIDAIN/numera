## 不得混淆的五种数学目标

| 任务 | E2 严格参考 | 边界反例 |
|---|---|---|
| Direct 准确商位 | 真商**截取**前两位有效商位（第三位作为显式可选参考），不是四舍五入或3% | `890÷371` 的正确两位为 `2.3`，但相对真实商偏差大于3%；`2.4` 即使近似够准也不是准确截位答案 |
| 综合/raw商 | 按**原始 A/B** 检验最终估计误差≤3%，不能只按截位核心检验 | 同一 `890÷371` 输入 `2.3` 对 Direct 正确，对近似任务不通过 |
| Split 块 | 带符号比例块的逐步和、对应量与首次满足原商3%的阶段 | `157÷354` 的 `50%-5%` 首次在第二步满足；`388÷1564` 一步25%即可。 `223÷10641` 的0.1%仅证明数学可行，**不代表获批比例词表** |
| Scaling 修正 | 实际 `B0-B` 的带符号差值、零阶、结果修正、A×r分子修正、粗商×Δ分子修正**分别建参考链** | `645÷122` 对125零阶可停；`645÷119` 对125用粗商5乘差6，修分子到675/125满足3%；粗商×Δ**不自动生成二阶公式** |
| 求r、N×r | 求r按严格比值显示到0.1个百分点；N×r两阶段各按5%，二阶沿**用户真实 C1** | `B=125,B0=167` 严格25.1%与名义×6快捷25.2%冲突，保持待审批；`856×0.042` 的二阶以用户第一步36继续 |

## 数据来源 / 准入边界

- 小P课堂示范数字与花生十三分式练习属于教学来源；研究台账中的变体/控制题需单独标注，不得冒充原题。
- 已做真题中提取的中间式必须与原题数字分开；不能对未做真题泄露解析。
- 数学可行 `math_status` **不等于** 当前工具支持 `supported_steps`、专项准入 `method_admission`、独立难度 `difficulty_candidate`、上线资格 `release_eligibility`。
- 该 oracle **不提供**路线成本胜者、L档、机器配额、老师实际心算步骤、用户未提交的计算链；任何 `R1/R2/R3` 仍处于产品待批状态。
- 所有计算函数只产生研究/测试参考事实：绝不自动填写训练 UI；不能直接拿它们当正式 grader。
