## 2. 用户事件与阶段的基本合同

| 层次 | 必须保存的语义 | 不能做的事 |
| --- | --- | --- |
| 未提交草稿 | 用户原始输入文本、符号、小数位、可恢复编辑状态 | 自动以真商覆盖草稿，或把没填的阶段推断为已完成 |
| 进入阶段 | 用户真正进入/退出的步骤序列，选定的当前分支、必要的修改记录 | UI显示过某字段就当作用户实际计算过 |
| 完成提交 | 用户**实际提交**的答案、完成的阶段、相关冻结题目身份 | 根据最终答案猜用户的心算方法 |
| 反馈 | 独立的终局数学结果与过程可观察诊断 | 使用未批准的局部5%/0.2pp作为硬判错线 |
| 历史 | v1旧问答、mixed、method_choice、旧长度保持读回放/导出 | 因新会话不准启动而删除旧记录 |

输入期允许负号、临时空串、保留小数位；解析与判分应发生在明确提交的边界。切换分支后不使用旧分支草稿算当前成绩，但有审计数据时不伪造过去从未选择过旧分支。

## 3. 分专项状态与动态字段

**Direct**：首位试商、乘回、余量、准确第二位（题目明确要求时继续第三位）；严格截取，不以最终3%提前停算。必须区分“2.3前两位正确”与“2.3原商误差超3%”两种目标。

**Split**：默认三栏但只记录真实填写的带符号比例、对应量及余量。1/2/3块与用户自选继续，满足原式3%后可以停，不强制补全三栏。步骤余量由用户自己报告，后台独立检查；当前不添加0.1%或0.2%基本块。

**Scaling**：用户自选B0、填带符号Delta；零阶真实Q0足够原商3%即可提交；修结果填写用户实际Q0、r、C1、Q1；修分子分两路径：粗商×Delta填写qrough、C1、A1、Q1（不强制先求r或Q0），A×r则填写r、C1、A1、Q1。二阶仅在确实需要且合法时主动进入；粗商Delta路径不能自动套标准r二阶。

**求r**：只展示B与B0并要求0.1个百分点输出；严格计算与快捷名义转换舍入冲突的数对先隔离。**N×r**：一阶只填写C1，二阶顺序填写用户真实U1和C2，第二步应依据用户U1，不能偷换为数学真C1。**综合**：自然原式，只交最终数值，不要求报告选法，后台按原式3%校验。

| --- | ---: |
| Direct、Split、Scaling、Comprehensive | 10 |

## 5. R3 双轴结果与禁止伪造

终局轴：Direct准确商位；Split/Scaling/综合原式相对误差≤3%；求r到0.1个百分点；N×r每步5%、第二步用真实上一阶。

过程轴：只有用户实际进入的步骤才可能评为一致、需复核或精度未知。建议研究状态 not_entered / consistent / review_needed / precision_unknown，不直接宣称已批准数据库字段名。最终正确但过程错，允许最终pass且过程review_needed；过程正确但终局错，则给出真实的计算误差线索。局部5%和r的0.2pp仅能做离线诊断候选，不改最终判分或稳定掌握。
